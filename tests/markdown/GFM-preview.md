## 代码围栏

普通段落后面无需空行：
````markdown
# 这行应显示为代码，不应显示成标题
```cpp
int main() {}
```
上面的短围栏不能关闭外层围栏。
````
这一行应恢复正常文本。

~~~text
反引号 ``` 不能关闭波浪号围栏。
~~~

## 公式

标题使用统一标题色；代码使用已有字符串色；公式使用已有紫色。
行内公式 $E = mc^2$，以及带反引号的公式 $`x_1 * x_2`$。
代码中的 `$E = mc^2$` 应保持代码颜色。
\$转义美元符号\$、价格 $5 和 $10 不应显示为公式。
[链接文字中的 $x_1$](https://example.com)。

$$E = mc^2$$

$$
\sum_{i=1}^{n} x_i^2
$$

```math
\frac{-b \pm \sqrt{b^2 - 4ac}}{2a}
```

此行应恢复正常文本。
